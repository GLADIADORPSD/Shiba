# SHIBA — O legado dos muitos nomes

Arquivo histórico colaborativo de personagens fictícios de GTA RP. Versão 0.3.

Site estático em português, sem dependências, APIs ou banco de dados. Para publicar no GitHub Pages, selecione Settings → Pages → Deploy from a branch → main → / (root).

## Contribuições

Biografias, vínculos e imagens autorizadas podem ser adicionados ao arquivo `index.html` e à pasta `assets/`. As hipóteses narrativas não representam fatos confirmados da história.
